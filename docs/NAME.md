# Naming

**Correct name:** **BIN-SYNC** (binary sync) / **BIN-SYNC CORE** (protocol) / **BinSync.Net** (.NET engine).

**Incorrect:** BYN-SYNC — historical typo / repo slug only.

| Artifact | Preferred |
|----------|-----------|
| Protocol | BIN-SYNC CORE |
| .NET package | BinSync.Core |
| Spec file | `BIN-SYNC-SPECIFICATION.txt` |
| Addendum | `BIN-SYNC-v2.3.7-ADDENDUM.txt` |
| GitHub repo | Prefer rename `BYN-SYNC` → `BIN-SYNC` in Settings → General |

Until the GitHub repository is renamed, clone URLs may still contain `BYN-SYNC`; that does not change the product name.
