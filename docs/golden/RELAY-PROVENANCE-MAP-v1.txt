- NamespaceId: 7
- Original author: same NodeId as LocalReplica

## Required assertions

1. Cursor and mapping keys share the same 49-byte root.
2. Cursor kind is `01`; mapping kind is `02`.
3. NamespaceId is little-endian u16.
4. OutboxSeq is big-endian u64 in the mapping key, so prefix-cursor order is destination sequence order.
5. JournalSeq is little-endian u64 in the mapping value; ChangeId is exactly 16 bytes.
6. Cursor marker is ASCII `RPM2`, followed by scanned JournalSeq, ACKed OutboxSeq, ACKed JournalSeq (little-endian u64 each), then the 32-byte mapping-set digest.
7. Mapping-set digest is the XOR of SHA-256(`key || value`) for every retained mapping row. Append and prune update it in the same Storage write batch as the rows and cursor; restart recomputes it from bounded prefix pages and compares in constant time.
8. No OriginSequence, payload, fingerprint or peer-specific ACK is stored in a mapping row.

T-pass must compare these bytes against actual persisted rows produced by the sample and reject any mismatch.
